# SideNav

A persistent vertical navigation sidebar for application dashboards and portals. Supports expanded and collapsed states with icon-only display in the collapsed mode.

## When to use

Use `SideNav` as the primary navigation surface in multi-section app layouts. For top-bar navigation use a `<nav>` with horizontal links; for contextual in-page navigation use anchor-tabs.

## State and persistence

Use `collapsed` and `onCollapsedChange` together when the application owns the
state. The callback reports the requested next boolean; the parent passes it
back through `collapsed`. Controlled mode does not read or write localStorage.
`initialCollapsed` is ignored while a controlled value is provided.

Without `collapsed`, the sidebar manages state itself. It starts from
`initialCollapsed ?? false`, then restores `"0"` or `"1"` from
`prokodo-adminSidebarCollapsed` after hydration. Toggle changes are saved when
storage is available. Storage errors leave navigation usable in memory.
`onCollapsedChange` reports toggle requests in both modes, not initial render,
storage restoration or parent prop changes. `onChange` is for navigation links.

The server fallback uses `collapsed ?? initialCollapsed ?? false`. Supply the
same controlled value on server and initial client render. Choose one ownership
mode for the component's lifetime. Existing uncontrolled consumers need no change.

## Accessibility and application integration

- `ariaLabel` labels the wrapping `<aside>`.
- The native toggle button supports Enter/Space and exposes `aria-expanded` and `aria-controls="sidenav"`.
- Supply localized toggle labels and `redirect.ariaLabel` for icon-only links.
- Set `active` for visual styling and `redirect["aria-current"] = "page"` for the current page; URL matching is application-owned.
- A mobile overlay's backdrop, Escape handling, focus trap/return, inert background and scroll lock belong to the application shell. Collapsing SideNav only produces an icon rail.

Use the [English](https://ui.prokodo.com/docs/components/sidenav) or
[German](https://ui.prokodo.com/de/docs/components/sidenav) integration guide for a
complete controlled example and server-rendering guidance.

## API

### `SideNavProps`

| Prop                | Type                                                     | Default              | Description                                                                                                     |
| ------------------- | -------------------------------------------------------- | -------------------- | --------------------------------------------------------------------------------------------------------------- |
| `items`             | `SideNavItem[]`                                          | —                    | Flat list of navigation items. Used when `sections` is absent or empty.                                         |
| `sections`          | `SideNavSection[]`                                       | —                    | Navigation organised into named sections. When non-empty, `items` is ignored.                                   |
| `headlineProps`     | `Omit<HeadlineProps, "children">`                        | —                    | Default props forwarded to every section's `Headline`. Section-level `headlineProps` take precedence.           |
| `descriptionProps`  | `Omit<HTMLAttributes<HTMLParagraphElement>, "children">` | —                    | Default props forwarded to every section's description `<p>`. Section-level `descriptionProps` take precedence. |
| `initialCollapsed`  | `boolean`                                                | `false`              | Initial uncontrolled state; restored storage may replace it after hydration.                                    |
| `collapsed`         | `boolean`                                                | —                    | Controlled state; parent owns updates and persistence. Takes precedence over `initialCollapsed`.                |
| `onCollapsedChange` | `(collapsed: boolean) => void`                           | —                    | Requested next state when the built-in toggle is activated in either mode.                                      |
| `collapsedIcon`     | `IconName`                                               | `"ArrowRight01Icon"` | Icon shown when nav is collapsed.                                                                               |
| `unCollapsedIcon`   | `IconName`                                               | `"ArrowLeft01Icon"`  | Icon shown when nav is expanded.                                                                                |
| `collapsedLabel`    | `string`                                                 | `"Expand menu"`      | Screen-reader label for the toggle when collapsed.                                                              |
| `unCollapsedLabel`  | `string`                                                 | `"Collapse menu"`    | Screen-reader label for the toggle when expanded.                                                               |
| `iconProps`         | `Omit<IconProps, "name">`                                | —                    | Extra props forwarded to the toggle icon.                                                                       |
| `ariaLabel`         | `string`                                                 | `"Main navigation"`  | Accessible label on the wrapping `<aside>`.                                                                     |
| `className`         | `string`                                                 | —                    | CSS class on the root `<aside>` element.                                                                        |
| `renderFooter`      | `() => ReactNode`                                        | —                    | Optional footer shown while expanded after hydration.                                                           |
| `onChange`          | `(item: SideNavItem) => void`                            | —                    | Called when a navigation link is clicked.                                                                       |

### `SideNavSection`

| Prop                | Type                                                     | Default | Required | Description                                                                                           |
| ------------------- | -------------------------------------------------------- | ------- | -------- | ----------------------------------------------------------------------------------------------------- |
| `items`             | `SideNavItem[]`                                          | —       | ✅       | Navigation items belonging to this section.                                                           |
| `headline`          | `string`                                                 | —       | —        | Plain-text section heading rendered via the internal `Headline` component (hidden in collapsed mode). |
| `description`       | `string`                                                 | —       | —        | Short description rendered below the headline.                                                        |
| `headlineComponent` | `ComponentType<{ className?: string }>`                  | —       | —        | Custom React component used instead of `headline` string.                                             |
| `headlineProps`     | `Omit<HeadlineProps, "children">`                        | —       | —        | Props forwarded to the section's `Headline` (overrides global `headlineProps`).                       |
| `descriptionProps`  | `Omit<HTMLAttributes<HTMLParagraphElement>, "children">` | —       | —        | Props forwarded to the section's description `<p>` (overrides global `descriptionProps`).             |

## Design Tokens

Customise `SideNav` via CSS custom properties on `:root` or a scoped ancestor.

| Token                                 | Default                                                      | Description                                       |
| ------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------- |
| `--pk-sidenav-bg`                     | `var(--pk-color-surface)`                                    | Background color of the sidebar panel             |
| `--pk-sidenav-shadow`                 | `var(--pk-shadow-md)`                                        | Box-shadow of the sidebar panel                   |
| `--pk-sidenav-toggle-hover`           | `var(--pk-color-surface-raised)`                             | Background color of the toggle button on hover    |
| `--pk-sidenav-link-hover-bg`          | `color-mix(in srgb, var(--pk-color-brand) 10%, transparent)` | Background color of nav items on hover/active     |
| `--pk-sidenav-link-active-bg`         | `color-mix(in srgb, var(--pk-color-brand) 5%, transparent)`  | Background color of the current page nav item     |
| `--pk-sidenav-icon-color`             | `var(--pk-color-fg)`                                         | Icon foreground color                             |
| `--pk-sidenav-icon-bg`                | `var(--pk-color-surface-raised)`                             | Icon wrapper background color                     |
| `--pk-sidenav-label-color`            | `color-mix(in srgb, var(--pk-color-fg) 70%, transparent)`    | Collapse icon and label color                     |
| `--pk-sidenav-fg`                     | `var(--pk-color-fg)`                                         | Main nav item label color                         |
| `--pk-sidenav-radius`                 | `var(--pk-radius-sm)`                                        | Border-radius for nav items and icon wrappers     |
| `--pk-sidenav-gap`                    | `var(--pk-space-xs)`                                         | Gap between nav list items                        |
| `--pk-sidenav-link-gap`               | `var(--pk-space-md)`                                         | Internal gap inside each nav item (icon ↔ label) |
| `--pk-sidenav-section-headline-color` | `color-mix(in srgb, var(--pk-color-fg) 45%, transparent)`    | Color of section headline labels                  |
