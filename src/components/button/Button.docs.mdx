# Button

Interactive call-to-action element supporting contained, outlined, and text variants, semantic colors, icon-only controls, redirects, and loading states. All visual variants share the same control height and typography.

## When to use

Use `Button` for any primary or secondary user action — form submission, navigation triggers, modal openers. Use `variant="text"` for low-prominence actions in toolbars or dialogs.

## Accessibility (WCAG 2.2)

- Renders a native `<button>` or an `<a>` through `BaseLink` when `redirect` is set
- Interactive icon-only buttons **must** provide an `aria-label`; use `inert` only for decorative controls
- Loading state sets `aria-busy="true"`, keeps the label width stable, and adds a spinner
- Native disabled buttons use `disabled`; redirected buttons use `aria-disabled` and are removed from the tab order
- Built-in color and ink pairs are designed for readable light and dark themes; re-check contrast after overriding tokens

### Keyboard behavior

| Key                 | Action                           |
| ------------------- | -------------------------------- |
| **Tab / Shift+Tab** | Move focus to / away from button |
| **Enter / Space**   | Activate button                  |

## API notes

- `title` is required for default buttons — visually rendered and used as accessible label
- `variant` controls visual weight: `"contained"` (filled) | `"outlined"` (border) | `"text"` (minimal)
- `color` maps to design-system tokens: `"primary"` | `"secondary"` | `"success"` | `"error"` | `"info"` | `"warning"` | `"inherit"`
- `iconProps` renders an icon inside the button; omit `title` for icon-only buttons and provide `aria-label`
- `iconPosition="start" | "end"` positions an existing icon without adding decorative elements
- `loading` shows a spinner and prevents interaction
- `redirect` switches the root to a geometry-compatible `BaseLink` anchor and forwards `href`, `target`, `rel`, `download`, `style`, and `linkComponent`
- `fullWidth` stretches the button to 100% of its container
- `priority` eagerly hydrates the interactive island; it has no visual effect

## Design Tokens

Customise via CSS custom properties on `:root` or a scoped ancestor element.

### Layout and typography

| Token                     | Default                          | Description                                      |
| ------------------------- | -------------------------------- | ------------------------------------------------ |
| `--pk-button-bg`          | `var(--pk-color-surface-raised)` | Default surface fallback.                        |
| `--pk-button-fg`          | `var(--pk-color-fg)`             | Default text/icon fallback.                      |
| `--pk-button-font-weight` | `600`                            | Label font weight.                               |
| `--pk-button-radius`      | `var(--pk-radius-pill)`          | Shared radius for every variant.                 |
| `--pk-button-padding-x`   | `var(--pk-space-xl)`             | Horizontal padding.                              |
| `--pk-button-padding-y`   | `1rem`                           | Vertical padding for contained, outlined, text.  |
| `--pk-button-min-height`  | `3.25rem`                        | Shared control height; icon-only uses it square. |
| `--pk-button-shadow`      | `var(--pk-shadow-sm)`            | Base fallback shadow.                            |

### Material and motion

| Token                                         | Default                          | Description                                |
| --------------------------------------------- | -------------------------------- | ------------------------------------------ |
| `--pk-button-hover-lift`                      | `-2px`                           | Vertical hover motion.                     |
| `--pk-button-press-scale`                     | `0.985`                          | Active-state compression.                  |
| `--pk-button-motion-duration`                 | `240ms`                          | Main interaction duration.                 |
| `--pk-button-motion-easing`                   | `cubic-bezier(0.22, 1, 0.36, 1)` | Main interaction easing.                   |
| `--pk-button-sheen-duration`                  | `560ms`                          | Contained sheen sweep duration.            |
| `--pk-button-sheen-opacity`                   | `0.32`                           | Contained sheen strength.                  |
| `--pk-button-contained-bottom-glow`           | `rgb(255 255 255 / 58%)`         | Soft inner bloom in the lower button half. |
| `--pk-button-contained-shadow-strength`       | `22%` (`30%` on primary)         | Resting semantic elevation strength.       |
| `--pk-button-contained-hover-shadow-strength` | `30%` (`38%` on primary)         | Hover elevation strength.                  |

### Semantic surfaces and ink

| Token family                               | Purpose                                                                              |
| ------------------------------------------ | ------------------------------------------------------------------------------------ |
| `--pk-button-contained-background-{color}` | Contained surfaces; component overrides exist for inherit, primary, info, and error. |
| `--pk-button-contained-foreground-{color}` | Solid icon/fallback foreground for every semantic color.                             |
| `--pk-button-contained-ink-{color}`        | Label gradient used by contained buttons.                                            |
| `--pk-button-content-{color}`              | Label/icon gradient used by outlined and text buttons.                               |
| `--pk-button-content-fallback-{color}`     | Solid fallback when gradient text is unavailable.                                    |

`{color}` is one of `inherit`, `primary`, `secondary`, `success`, `info`, `warning`, or `error`. Dark mode swaps these tokens automatically, including a softer charcoal contained foreground.

```css
.checkoutCta {
  --pk-button-contained-background-primary: linear-gradient(
    112deg,
    #4aa8ff,
    #43ecff
  );
  --pk-button-contained-bottom-glow: rgb(255 255 255 / 64%);
}
```

## ✅ Do

- Use clear, action-oriented labels: "Save changes", "Delete project"
- Always supply `aria-label` when `title` is absent (icon-only)
- Use `loading` to give feedback during async operations

## ❌ Don't

- Don't use a `<button>` for navigation without `redirect` — use `redirect` so an `<a>` is rendered
- Don't disable buttons without explaining why; prefer validation error messages instead
- Don't mix `variant="contained"` for more than one primary action per screen
